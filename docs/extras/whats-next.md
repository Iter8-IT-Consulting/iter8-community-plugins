# What's Next

**Lost track? It tells you where you are and what to do now.**

Back after a week away? Not sure whether to build or ship? Ask What's
Next. It looks at your project (the board, what's built, what's live,
anything half-finished) and gives you one clear recommendation, with
the reason.

## What it sounds like

> **SlideIt** is live at slideit.vercel.app (v0.2.0). Two stories are
> built but not live yet, and you're partway through *Presenter can
> reorder slides*.
>
> **Next: finish that story with Build It.** Then all three can go live
> together with Ship It.
>
> Start Build It now?

## How it decides

It goes down the journey in order and stops at the first thing that needs
doing: a missing step, then unfinished work, then what's waiting to ship,
then the next card in Todo. If Todo's empty, it suggests
[Trim It](../steps/06-trim-it.md) to choose what's next.

It only looks. It never changes anything. Say yes, and it starts the
step it recommended.

It also tells you which version of iter8-it you're running, handy after
an update.
