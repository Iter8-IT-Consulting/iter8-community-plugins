# Claim It

**Claim your name on the internet: a real project and a live page, so it's
real from the start.**

This is the moment the idea becomes a place. Before you've built a single
feature, your app has a home page at its own web address, a project board
to plan on, and automatic checks guarding every change. Everything after
this builds on something real.

## What happens

Claude checks everything first and asks before creating anything: which
GitHub account and organization, which Vercel team, and whose name goes
on the work. Then, mostly while you watch:

- **The app**: a starter Next.js app showing your name and purpose,
  with tests that already pass.
- **The code's home**: a private GitHub repository.
- **The board**: Backlog, Todo, In Progress, In Review, Done, with two
  views: a Tracking Board (cards in columns) and an Issue List (a table).
  Empty for now; your ideas go here in Dream It.
- **Automatic checks**: every change is tested on GitHub before it can
  go live.
- **Hosting**: a Vercel project connected to the code. Only the
  finished, checked version is ever published.
- **Go live**: the first deploy, then a check that the live page really
  works, on a desktop and on a phone.

## What you end up with

- A live web address you can open on your phone and share.
- A code repository, a board and automatic checks, all set up the same
  proven way.
- A starter page with light Iter8 Community branding: easy to keep,
  restyle or remove.
- A **style guide** page (`/style-guide`) showing the app's colours,
  fonts and pieces. [Skin It](07-skin-it.md) gives the app its own look.

**No database yet.** That comes later, and only if your app needs one.

## What it asks of you

| | |
|---|---|
| **Time** | 15-20 minutes, mostly waiting on installs and builds |
| **Decisions** | Where it lives (GitHub, Vercel), private or public, the name on your work |
| **You'll need** | Free GitHub and Vercel accounts, signed in on your computer |
| **Cost** | Nothing. Free plans cover it. |
