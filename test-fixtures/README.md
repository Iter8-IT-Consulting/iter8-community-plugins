# Test fixtures

`PRODUCT.md` + `journey.json` at a given stage, so any skill can be started
mid-journey. Copy a folder's contents into an empty test folder, then run
the step that comes next.

| Folder | State | Next step |
|---|---|---|
| `after-name-it/` | Problem, name, slug and purpose. Nothing online. | Claim It |

The slug is a throwaway (`itplug-test-<n>`). Change `<n>` in `journey.json`
if a previous test run hasn't been torn down yet.
